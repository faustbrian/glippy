# Gox v0.1.0 To Glippy v1 Formatter Delta

This is the complete formatter-behavior delta from Gox v0.1.0 to the Glippy
v1 draft. It distinguishes changed behavior from coverage added without a
behavior change. Every listed change is a correction to comment or directive
ownership; there is no deliberate layout-policy change.

Gox v0.1.0 already formatted ordinary call arguments, composite elements and
openings, function openings, function-literal openings, and field
documentation with line-scoped suppressions. Those constructs are not v1
changes. The exact old tests remain in the
[`v0.1.0 formatter suite`](https://github.com/faustbrian/glippy/blob/v0.1.0/internal/format/format_test.go).

## Complete Construct Inventory

| Affected construct | Gox v0.1.0 | Glippy v1 | Classification |
| --- | --- | --- | --- |
| Comment between a label and its nested statement | Refused: no proven comment owner | Formats the statement and indents the comment below the label | Correction |
| Standalone or trailing comment after a closing label | Refused: no proven comment owner | Preserves the comment and implicit closing empty statement | Correction |
| Label suppression or mixed comment/directive gap before a nested or implicit-empty statement | Refused: no proven comment owner | Preserves physical directive ownership and required blank gaps | Correction |
| Declaration documentation before a trailing `//nolint` | Refused: comment identity/order changed | Formats the declaration while retaining documentation and suppression lines | Correction |
| Grouped value spec with a trailing `//nolint` | Refused: directive anchor changed | Formats the spec without moving its suppression | Correction |
| Top-level call-initialized declaration with a trailing `//nolint`, including a boundary before following documentation | Refused: directive anchor changed | Preserves only the affected declaration and formats unaffected declarations | Correction |
| Simple top-level declaration whose trailing `//nolint` anchor remains stable | Preserved the declaration verbatim | Canonicalizes ordinary spacing while retaining the physical anchor | Correction of unnecessary fallback |
| Composite-literal opening nested in a call, including a compressed containing block | Refused: directive anchor changed | Preserves only the affected declaration | Correction |
| Binary assignment or return containing that suppressed nested call | Refused: directive anchor changed | Preserves only the affected declaration | Correction |
| Labeled statement containing that suppressed nested call | Refused: directive anchor changed | Preserves only the affected declaration | Correction |
| Struct field suppression followed by a blank grouping gap | Refused: directive anchor changed | Preserves the field and gap | Correction |
| Inline struct field suppression in a plain type, a generic type with a broken prefix, or a grouped type declaration | Refused: directive anchor changed | Preserves only the affected declaration | Correction |
| Blank line between trailing top-level directive groups | Refused: directive anchor changed | Preserves both groups and their blank separator | Correction |
| Block comment before `else`, between `else` and its block, or between `else` and `if` | Refused: no proven comment owner | Preserves the comment at the exact keyword boundary | Correction |
| Line comment after `else` | Refused: no proven comment owner | Keeps the comment after `else` and moves the block brace to the next line | Correction |

The current executable coverage is
`TestFormatPreservesCommentBetweenLabelAndStatement`,
`TestFormatPreservesCommentAfterClosingLabel`,
`TestFormatPreservesLabelDirectiveLineOwnership`,
`TestFormatPreservesDeclarationDocumentationBeforeTrailingNolint`,
`TestFormatPreservesGroupedValueSpecLineBeforeTrailingNolint`,
`TestFormatPreservesNolintOwnershipAcrossBreakableBoundaries`, the
`TestFormatDirectiveFallback*` family,
`TestFormatCanonicalizesStableTopLevelNolintDeclarations`,
`TestFormatDeclarationFragmentUsesNolintFallback`,
`TestFormatPreservesBlankLinesBetweenTrailingDirectiveGroups`,

## Label Boundaries

For each input in this section, Gox v0.1.0 returned exit 6 with no formatted
source because the comment had no proven output owner.

### Nested statement

Input:

```go
package labels
func run(){goto target;target:
// explain target
work()}
```

Glippy v1 output:

```go
package labels

func run() {
	goto target
target:
	// explain target
	work()
}
```

### Closing labels

Inputs with either a standalone or trailing comment were refused:

```go
package labels
func run(){goto done;done:
// explain closing label
}
```

```go
package labels
func run(){goto done;done: // explain closing label
}
```

Glippy v1 outputs, respectively:

```go
package labels

func run() {
	goto done
done:
	// explain closing label
}
```

```go
package labels

func run() {
	goto done
done: // explain closing label
}
```

### Label suppressions and gaps

Input:

```go
package labels
func run(){
goto target
target: // keep suffix

//gox:ignore example because gap matters
work()}
```

Glippy v1 output:

```go
package labels

func run() {
	goto target
target: // keep suffix

	//gox:ignore example because gap matters
	work()
}
```

The same contract covers an implicit closing empty statement, a trailing
`//nolint`, a suppression immediately before the closing brace, and a blank
gap after either directive. Glippy preserves those physical lines instead of
inventing an owner.

## Declaration Boundaries

### Documentation and a trailing suppression

Gox v0.1.0 refused:

```go
package comments
// errUnavailable documents the declaration.
var errUnavailable = errors.New("unavailable") //nolint:unused
```

Glippy v1 outputs:

```go
package comments

// errUnavailable documents the declaration.
var errUnavailable = errors.New("unavailable") //nolint:unused
```

### Grouped value spec

Gox v0.1.0 refused this directive anchor:

```go
package comments
var (
	devNumber = uint64(stat.Rdev) //nolint:nolintlint,unconvert
	major = unix.Major(devNumber)
)
```

Glippy v1 outputs:

```go
package comments

var (
	devNumber = uint64(stat.Rdev) //nolint:nolintlint,unconvert
	major = unix.Major(devNumber)
)
```

### Selective declaration fallback

Gox v0.1.0 refused this input when formatting the call-initialized declaration
would move its trailing suppression:

```go
package comments
var   errUnavailable=errors.New("unavailable") //nolint:unused
func ordinary(){value:=call(first,second)}
```

Glippy v1 preserves that declaration but continues formatting the unaffected
declaration:

```go
package comments

var   errUnavailable=errors.New("unavailable") //nolint:unused
func ordinary() {
	value := call(first, second)
}
```

The same fallback retains a blank line or documentation boundary after the
protected declaration. It is declaration-scoped, not a whole-file verbatim
fallback.

When the anchor is stable, v1 no longer preserves unnecessary spacing. Gox
v0.1.0 output:

```go
package comments

var   value=1 //nolint:unused
```

Glippy v1 output:

```go
package comments

var value = 1 //nolint:unused
```

## Nested External Suppression Anchors

For every changed variant below, Gox v0.1.0 returned exit 6 with
`directive source anchor changed` and no source. Glippy v1 emits the displayed
affected declaration byte-for-byte; ordinary declarations elsewhere in the
file still receive canonical formatting.

### Nested call and composite literal

```go
func run() {
	http.SetCookie(w, &http.Cookie{ //nolint:gosec
		Name: "sort",
	})
}
```

The same correction covers a compressed block containing the call. The
declaration remains verbatim because changing its layout would move the
external line-scoped suppression.

### Enclosing binary expressions and label

```go
func assign() {
	result := extremelyLongPrefixExpressionThatExceedsConfiguredFormattingWidth + outer(firstArg, &Config{Unsafe: true, //nolint:gosec
	}, thirdArg)
	_ = result
}

func returnValue() int {
	return extremelyLongPrefixExpressionThatExceedsConfiguredFormattingWidth + outer(firstArg, &Config{Unsafe: true, //nolint:gosec
	}, thirdArg)
}

func labeled() {
	target: outer(firstArg, &Config{Unsafe: true, //nolint:gosec
	}, thirdArg)
	goto target
}
```

### Field gaps and inline aggregate fields

```go
type Account struct {
	Password string `json:"password"` //nolint:gosec

	password []byte
}
```

```go
type Inline struct { Password string //nolint:gosec
}

type Generic[
	First any,
	Second any,
	Third any,
	Fourth any,
	Fifth any,
	Sixth any,
] struct { Password string //nolint:gosec
}

type ( Grouped struct { Password string //nolint:gosec
} ; Alias = Grouped )
```

Gox v0.1.0 already preserved a field suppression followed immediately by field
documentation or a standalone comment, plain composite openings, call
arguments, function openings, and function-literal openings. Their additional
v1 fixtures are regression coverage, not formatter changes.

## Trailing Directive Groups

Gox v0.1.0 refused this valid file because the blank line changed a directive
anchor:

```go
package internal

//go:generate first
//go:generate second

//go:generate third
//go:generate fourth
```

Glippy v1 emits it unchanged, retaining two directive groups rather than
merging them.

## `else` Comment Placements

Gox v0.1.0 refused this input because each comment had no proven output owner:

```go
package control
func before(value int){if value==0{work()} /* zero */ else{retry()}}
func between(value int){if value==0{work()}else /* nonzero */{retry()}}
func line(value int){if value==0{work()}else // nonzero
{retry()}}
func chain(value int){if value==0{work()}else /* retry */ if value==1{retry()}}
```

Glippy v1 produces:

```go
package control

func before(value int) {
	if value == 0 {
		work()
	} /* zero */ else {
		retry()
	}
}

func between(value int) {
	if value == 0 {
		work()
	} else /* nonzero */ {
		retry()
	}
}

func line(value int) {
	if value == 0 {
		work()
	} else // nonzero
	{
		retry()
	}
}

func chain(value int) {
	if value == 0 {
		work()
	} else /* retry */ if value == 1 {
		retry()
	}
}
```

These are four distinct ownership boundaries: before `else`, after `else`
before a block, a line suffix after `else`, and after `else` before an `if`.

## Evidence And Migration

Every correction is covered by focused golden assertions and the ordinary
file/fragment equivalence and idempotency gates. The pinned 17-repository
formatter, source-fidelity, idempotency, comment, and directive results are
recorded in the
[v0.8 exit audit](../research/v0.8-exit-audit-2026-08-26.md). The exact v1
formatter fingerprints are frozen by
[`testdata/contracts/v1/formatter.txt`](../../testdata/contracts/v1/formatter.txt).

Users upgrading from Gox v0.1.0 should run `glippy fmt --check` or
`glippy fmt --diff`. The changed cases were mostly prior refusals, so ordinary
successfully formatted v0.1 source retains the same layout policy. The stable-
anchor declaration correction may produce a new canonical spacing diff around
a trailing external suppression; it is classified as a correction because v1
formats ordinary whitespace whenever physical directive ownership remains
provable.
