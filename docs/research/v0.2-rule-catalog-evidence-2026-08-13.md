## Requested Bug-Catching Coverage

All sixteen requested capability areas have an admitted v0.2 rule or documented
standard-library family audit: identical branches, self assignment, almost
swapped assignments, impossible comparisons, bad bit masks, contradictory and
subsumed conditions, defer in loops, resource ownership, discarded errors,
copied locks, loop capture, impossible type assertions, suspicious range
mutation, locks held across blocking calls, and context/errors/time/HTTP/atomic
API misuse.

The expanded standard-library audit admits `context-cancel-leak`, `nil-context`,
`errors-as-target`, `time-duration-unit`, `time-layout`,
`http-response-before-error`, `http-canonical-header-key`, and
`atomic-update-assignment` alongside the earlier context and errors rules. It
rejects obsolete supported-version timer advice and defers target-specific or
ownership contracts that lack sufficient precision.

## Go Vet Compatibility Pack Evidence

The fifteen-rule 2026-08-14 expansion has exact positive and nearby-negative
fixtures, generated-file and type-error policy tests, suppression and
source-version gates, deterministic JSON/baseline/explain coverage, and
suggestion mapping for every upstream fix. Unambiguous `printf`, `unreachable`,
and `hostport` suggestions additionally pass formatted, validated, repeated CLI
application. Each rule has a dated admission record under `docs/research`.

One-iteration typed package probes on Go 1.26.6 darwin/arm64 ranged from
99,869,417 ns (`append-no-values`) to 587,996,708 ns (`printf-arguments`). These
include package loading and are proportional admission evidence rather than a
stable latency budget. Non-mutating dogfood enabled only these fifteen rules and
found no diagnostics across 178 Glippy files or 57 files in
`go-libraries/pkg/prompts` at
`2c9842015ab62fd7790f0d99bf54855ffa7000f2`; the target's pre-existing wider
repository dirt was not modified.

`needless-blank-identifier`, `redundant-closure`, `redundant-nil-check`,

These Go 1.26.6 Darwin arm64 probes include complete package loading and are
proportional evidence rather than stable latency budgets. The initially broad
`unnecessary-format` contract flooded Glippy dogfood through ordinary logging
and error calls; a red noise regression narrowed it to no-argument `fmt.Sprintf`
calls with constant formats before admission. The final eight-rule selection
produced no diagnostics in Glippy or `go-libraries/pkg/prompts` at
`f0067b6dbf812c770ec663249e9abc3f2c41d1bc` without modifying either tree.

Five product-owned transformations are now suggestion-only:
`unnecessary-conversion`, `unnecessary-sprintf`,
`needless-blank-identifier`, `time-since`, and `time-until`. Focused replacement
tests and the public `lint --fix-suggestions` path prove exact edits, complete-
file formatting, typed validation, and repeated fixed-point behavior. A fix
that would leave an unused import is rejected by final validation rather than
silently broadening expression ownership into import organization.

## Remaining Pedantic Deferrals

Broad allocation, interface-breadth, signature-complexity, documentation, and
nested-flow rules remain deferred until their precision and configuration
contracts have real-code evidence. Redundant closures are admitted only for
direct, identically typed delegation; general function-literal simplification
remains out of scope. See the admission records for the exact boundaries.
