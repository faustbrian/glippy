## Conservative Boundaries

Recursive testing-failure wrapper cycles remain unclassified. The shared
no-return analysis rejects cyclic proof rather than assuming that a finite
terminal path dominates the cycle. Acyclic selected-module wrappers remain
bounded by the existing recursion limit.

The v0.6 adjudication artifacts remain immutable historical evidence. The v0.8
exact rerun must confirm that the 25 precision entries no longer report and
must classify the containerd fuzz-target entry as `intentional` in both default
and recommended profiles. It must also rerun formatter, fix-rehearsal, variant,
and resource gates. No external corpus repository was modified.

Local verification deliberately excluded process-control, descendant cleanup,
runtime interruption, and RSS probes because those tests are unsafe on the
shared workstation. Cross-platform resource evidence must run in isolated CI.
