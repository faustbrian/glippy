# v0.8 Upgrade Rehearsal, 2026-08-25

## Decision

Glippy revision `3b4524e6cf1d169ba6a9e0e907d363f9eaada942` preserves the
configuration and baseline contracts exercised by the historical Gox v0.1.0
release and the first Glippy source revision. This closes the bounded v0.8
prerelease-upgrade rehearsal; it is not a v1 compatibility freeze or release
candidate claim.

The Gox configuration uses the historical singular `lint.preset` field. The
early Glippy configuration uses `lint.presets` and enables a schema-v1 baseline
containing one `duplicate-condition` entry. The early binary reported that
diagnostic before baseline creation. The current clean binary reported version
`glippy v0.1.1-0.20260825033757-3b4524e6cf1d` and consumed both fixtures
without configuration, source, stale-baseline, or finding outcomes.

The retained fixtures are immutable test inputs. Rehearsal binaries, build
caches, analysis caches, and working copies were task-owned. The checks were
local, offline after dependency acquisition, and did not modify an external
repository.

## Boundaries

This rehearsal covers the concrete version-1 configuration fields and baseline
schema produced by Glippy's own history. It does not promise acceptance of
unknown fields, malformed configurations, future schema versions, arbitrary
third-party baseline edits, or persistent cache compatibility. The v0.9
contract freeze must repeat the supported upgrade matrix against its final
tagless candidate.
