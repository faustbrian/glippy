## Evidence

Exact pinned-corpus run `32826933418` at Glippy revision `8470e88` completed
Containerd revision `6c12665e1c31e7728d0e0eb1224288bd9153114b` without a tool
failure, but retained the two historical `unchecked-writer-error` precision
findings in `cmd/ctr/commands/content/fetch.go` and
`cmd/ctr/commands/images/push.go`. This contradicted the bounded v0.7 claim that
selected-package nil `Write` result facts alone removed those findings.

The exact shared source shape constructs a `text/tabwriter.Writer` over
`pkg/progress.Writer`, passes the tab writer to `content.Display`, and then
discards `tabwriter.Flush`. `progress.Writer.Write` only delegates to an
internal `bytes.Buffer`, so the tab-writer flush cannot fail. The later
`progress.Writer.Flush` remains the separate fallible output boundary.

## First Divergence

The selected-package nil-result fact was present, but stable-writer analysis
correctly invalidated the chain when it crossed `content.Display`. The v0.7
synthetic fixture called no intermediate writer consumer and therefore did not
exercise the pinned source boundary.

An exact-shape regression reproduced the diagnostic only after adding the
cross-package display call. Named results, a local sink binding, and looped
construction were not independently responsible.

## Correction

The shared effect model now publishes a separate package-variant-intersected
synchronous writer-borrow fact. A function qualifies only when an exact
`io.Writer` parameter is used directly by `Write`, the non-retaining
`fmt.Fprint` family, `io.WriteString`, or another proven borrower. Storage,
return, closures, goroutines, defers, type assertions, aliases, unknown calls,
and recursive proof remain conservative.

Buffered-writer stability consumes that fact only for a statically mapped
`io.Writer` argument on an immediate call. Deferred and asynchronous call sites
remain conservative. The regression retains diagnostics for a consumer that
stores the writer, a fallible sink, and an interface-dispatched sink.

The native effect schema and cache component advance to version 17 and
`native-effects-v17`. The exact Containerd and complete pinned corpus must rerun
at the corrected pushed revision before the two historical false positives can
be removed from v0.8 adjudication.
