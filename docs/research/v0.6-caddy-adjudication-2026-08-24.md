## Decision

Treat a final unlabeled `break` or `continue` as an intentional testing
termination shim when it is the sole remaining statement after an exact
`testing.FailNow`, `Fatal`, or `Fatalf` call. This extends the same bounded
source proof already used for NATS bare returns. Labeled branches, nonfinal
branches, retained work, non-testing lookalikes, and other no-return calls keep
their diagnostics.

Break reachability is counted per owning loop, switch, or select. Suppressing
an unreachable testing shim removes only that branch's edge, so it cannot make
code after an otherwise terminal construct appear reachable and cannot erase a
separate reachable break in the same construct.

Retain the writer, response-body, and scanner findings. They identify errors or
resources that the affected tests and command paths can otherwise hide.
