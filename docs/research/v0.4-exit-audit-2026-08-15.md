# v0.4 Interprocedural Precision And Fix Maturity Exit Audit, 2026-08-15

## Decision

The v0.4 development milestone is complete. It advances existing rules and
fixes through shared interprocedural facts, import-aware transactions,
standard-library correctness coverage, opt-in execution statistics, and a
diverse pinned corpus. It does not publish, tag, or claim release readiness.

The canonical catalog now contains 101 rules. Earlier v0.3 records correctly
describe the 100-rule snapshot at `3ac8b5f5b8ffdef5c1e7124961eda2a716150bbe`;
`exec-pipe-run` was admitted afterward and is the 101st current rule.

## Cross-Package Fact Safeguards

- Unknown, conflicting, delegated, aliased, recursive, dynamic, interface, and
  unsupported external-module behavior remains conservative.
- Facts are keyed by canonical package-qualified object strings, never by
  process pointers.
- Dependency scheduling is deterministic and limited to selected root modules;
  the standard library and third-party module bodies are not speculatively
  retained.
- The `native-effects-v3` digest binds schema version, ordered identities,
  parameter effects, and returned-state relationships into native cache keys.
- Root and fact loads share package, file, byte, cancellation, and source-error
  bounds.
- CFG, native unreachable-code traversal, and SSA use the same no-return
  predicate, so deeper tiers cannot disagree about a summarized terminal call.

The admitted boundary does not infer arbitrary aliases, delegated results,
third-party effects, or every `go.work` module. Those are explicit false
negative boundaries rather than optimistic facts.

## Performance Budget And Limits

On the recorded Apple M4 Max/Darwin arm64 host, the pinned suspicious-policy
corpus must remain within 40 seconds cold, 12 seconds warm, and 8 GiB peak RSS.
All recorded samples pass. This is a bounded development regression budget,
not a portable performance promise. Caddy, sqlc, and NATS peak between roughly
5 and 7.65 GB, so v0.4 does not claim Clippy-like memory efficiency.

Stats-mode allocation measurements are observational and include process-wide
concurrent work; subprocess allocations are excluded. Ordinary-run wall time
and RSS, not stats-mode counters, own the reference-host budget.

## Verification Boundary

Focused red-green regressions cover returned effects, import insertion and
cleanup, generated typed targets, batched package refresh, contextual
conversion typing, receiver consistency, semantic error APIs, range precision,
and imported no-return reachability. The unreachable-code suite covers
contiguous regions, nested branches, labels and gotos, declarations, infinite
and breakable loops, shadowed panic, nested function literals, compiler-required
return terminators, intentional test skips, type errors, generated files,
suppressions, exact suggestion ranges, and repeated fix application. The final
tree passed the complete Go test suite, `go vet`, module
tidiness, generated rule documentation, self-check, and diff hygiene with
task-owned build caches. The original chi contextual-shift and Caddy
defined-boolean findings no longer report; valid conversion suggestions still
apply and reach an idempotent second run.

The external corpus is disposable evidence, not human-approved upstream
adoption. Windows is unsupported. Network/distributed/userspace filesystem
writes, forced-power-loss durability, publication, signing, tags, and releases
remain outside this milestone.
