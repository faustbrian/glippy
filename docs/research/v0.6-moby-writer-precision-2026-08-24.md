## Decision

Retain `unchecked-writer-error` in the default correctness profile and add
three bounded exclusions:

1. A deferred `archive/tar.Writer.Close` is redundant only when a later
   same-block Close on the same directly declared local writer passes its error
   to another call, no return or branch can bypass that call, the writer does
   not escape, and no writer use follows it. Package bindings and receivers
   declared outside that block remain diagnostics because an unobserved helper
   can rebind them between the deferred and observed calls.
2. Stable in-memory fmt provenance accepts exact `time.Time` values in addition
   to basic values. User-defined formatting callbacks remain conservative
   because they can capture and reinitialize the writer.
3. A finalizer in a `_test.go` file is an expected-panic assertion only when
   the immediately preceding unconditional same-block defer compares the exact
   predeclared `recover()` result with nil, its sole nil branch calls an exact
   testing failure method, and the finalizer is the function body's terminal
   action.

Conditional closes, earlier normal returns, different, package-bound, or
escaped writers, later writer use, custom formatters, conditional recovery
registration, nonterminal finalizers, intervening defers, lookalike recover
functions, nested-block guards, asynchronous finalizers, and non-test files
keep their diagnostics. These are semantic source proofs, not Moby paths,
names, comments, or repository-specific suppressions.

## Behavioral Evidence

The redundant-close regression initially produced four diagnostics instead of
the three original conservative negative cases. A review regression then
proved that a mutable package receiver was incorrectly suppressed. The fmt
regression initially reported both the exact `time.Time` consumer and a custom
formatter that reinitializes the writer. The expected-panic regression
initially reported all three original fixtures instead of retaining only the
missing and conditional recovery guards. Review regressions then proved that a
nonterminal finalizer and a finalizer preceded by another defer were
incorrectly suppressed. A final test-quality audit also proved that treating a
nested block as terminal could let a later outer panic satisfy the guard. The
focused regressions pass after the production changes, and the complete
`TestUncheckedWriterError` suite remains the affected rule gate.
