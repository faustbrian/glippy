# v0.5 Native Typed-Budget Calibration, 2026-08-21

## Decision

The portable cold typed-analysis ceiling is provisionally 105 seconds while
the 2,147,483,648-byte peak-RSS ceiling remains unchanged. This replaces the
unproven 40-second native-runner value; it does not replace the separate
40-second Apple M4 Max reference-host gate.

The 105-second value applies only to the pinned release campaign over
`sqlc-dev/sqlc` revision
`8a7cddfbb9088666eb981645285d7699e71dcb54`, using the default correctness
policy plus `-Wsuspicious` and Go 1.26.5. It is not an editor-latency promise.

## Red Native Evidence

Exact Glippy candidate `df650658083aa6ef5cc0cf9ea6d59bd6890f78f8` ran in
[workflow `32464981182`](https://github.com/faustbrian/glippy/actions/runs/32464981182)
on all four supported native runners. Every job passed editor latency and all
five formatter samples, then rejected the first cold typed sample solely on the
40-second elapsed-time ceiling:

| Runner | Editor maximum | Formatter elapsed range | Formatter peak RSS range | Cold typed elapsed |
| --- | ---: | ---: | ---: | ---: |
| Linux arm64 | 6.108 ms | 17.020-17.320 s | 1,121,865,728-1,589,841,920 B | 49.740 s |
| Linux amd64 | 5.105 ms | 19.480-20.320 s | 1,118,015,488-1,443,991,552 B | 51.260 s |
| Darwin arm64 | 14.444 ms | 18.060-21.980 s | 1,419,575,296-1,638,891,520 B | 64.100 s |
| Darwin amd64 | 54.877 ms | 27.690-55.070 s | 1,438,257,152-1,842,573,312 B | 78.660 s |

The benchmark checks peak RSS before elapsed time. Reaching the elapsed-time
failure therefore proves that every cold typed sample remained within 2 GiB.
The jobs stopped at the first typed sample, so this run does not prove warm
latency, diagnostic stability on all targets, candidate construction, or
cross-runner reproducibility.

## Calibration Basis

The 40-second value came from the Apple M4 Max reference-host campaign and was
added to the native workflow before any native typed run. The failure is a
missing portable calibration, not evidence of a new source regression: all four
architectures cross the same threshold, while their editor, formatter, and RSS
contracts remain within budget.

The existing formatter calibration set its provisional native ceiling 33%
above the slowest first observation. Applying the same method to the 78.660-
second Darwin amd64 typed sample yields 104.618 seconds, rounded to 105 seconds.
This preserves a measured regression boundary instead of disabling or
arbitrarily widening the gate.

## Green Gate

The calibration is not stable evidence until the exact updated candidate runs
all five typed samples on Darwin and Linux, amd64 and arm64, preserves the
Darwin arm64 diagnostic fingerprint, constructs each release candidate, retains
all raw artifacts, and passes cross-runner reproducibility. A failed rerun must
be investigated rather than widening the ceiling again without new evidence.
