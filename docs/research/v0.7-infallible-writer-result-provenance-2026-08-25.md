# v0.7 Infallible Writer Result Provenance, 2026-08-25

## Decision

Propagate an exact unconditional nil result fact for selected-module
`Write([]byte) (int, error)` methods through bounded static delegation rooted in
`bytes.Buffer.Write` and `strings.Builder.Write`. `unchecked-writer-error` may
use that fact when a stable standard-library buffered writer terminates at the
proven concrete sink.

## Corpus Evidence And First Divergence

Pinned containerd revision `6c12665e1c31e7728d0e0eb1224288bd9153114b`
contains two tab writers whose sink is `pkg/progress.Writer`. Its `Write` method
only appends to an internal `bytes.Buffer`, so `tabwriter.Flush` cannot return an
underlying write error. The later `progress.Writer.Flush` calls perform the
fallible output and remain outside this exclusion.

The first divergence was the package boundary. Local stable-writer analysis
already proved direct and package-local in-memory chains, but discarded the
constructor when its concrete sink was defined in another selected package.
The shared result-state engine already carried unconditional nilness across
those package loads, but the writer rule did not consume it.

## Precision Contract

The sink must have an exact concrete `Write([]byte) (int, error)` method whose
error result is nil on every explicit normal return. Static delegation may
cross selected local-source packages and terminates only at the authoritative
standard-library in-memory writer roots. Package variants must agree.

Interface-typed sinks, dynamic calls, unavailable source, recursive summaries,
fallible delegates, conditional or conflicting returns, receiver escape,
reinitialization, and unstable constructor chains remain diagnostics. The fact
describes only `Write`; another method on the same concrete type may remain
fallible.

## Scheduling And Cache Boundary

`unchecked-writer-error` now requires the shared control-flow tier and native
effect facts rather than performing an uncoordinated dependency analysis. The
effect schema and cache component advance from version 15 to version 16, and
the existing canonical result-state digest binds the new selected-module facts.

## Behavioral Evidence

The imported-sink regression initially reported both the in-memory and fallible
tab-writer flushes. The final contract suppresses only the in-memory sink and
retains the fallible delegate. The complete pinned corpus remains a v0.8 rerun
gate; no external repository is modified.

## Revisit Triggers

Do not infer infallibility from type or method names, comments, test files, or a
single return path. Broaden authoritative roots only when the active Go
toolchain documents an exact always-nil writer contract and behavioral tests
retain fallible and interface-dispatched neighbors.
