# v0.5 Delegated Result-State Facts, 2026-08-20

## Decision

Allow unconditional result-state inference to consume exact static delegation
through a bounded, recursion-rejecting selected-package traversal. Advance the
native effect schema and persistent-cache component to `native-effects-v9`.

## Observable Contract

A direct single-result call maps result zero only when the callee exposes one
exactly identical result type. A sole multi-value return expression maps each
caller result to the same callee index only when both signatures have the same
arity and exact result type at that index.

Same-layer source definitions resolve lazily through at most 4,096 active
definitions. A function already active in the traversal is a recursive cycle
and contributes no state. Imported selected-package calls consume only stable
facts completed by an earlier dependency layer. Dynamic calls, conversions,
different arities or result types, unavailable facts, and every unknown callee
state remain unknown.

Every ordinary explicit-return, named-result mutation, typed-nil, package-
variant intersection, and cache-digest invariant from version 8 remains in
force. A function already proven not to return, or whose direct deferred call
or deferred function literal is proven not to return, publishes no result state
because its syntactic return never completes normally.

## Behavioral Evidence

The focused result-state regression initially classified direct nil, direct
non-nil, and same-arity tuple wrappers as unknown. It now preserves the exact
callee state while direct and mutual recursion remain unknown.

Safety review then reproduced a false nil fact for explicit returns followed by
an always-panicking deferred closure and by a deferred exact local no-return
helper. The result analysis now shares the existing no-return predicate and
rejects both while retaining unrelated defers that can complete normally. A
separate red regression protected an unreachable explicit nil return after an
exact local no-return helper.

The package regression adds a selected helper package, a delegating package,
and the analyzed root. Before the change, `nil-error-wrap` reported the four
direct cases and missed both delegated `%w` operands. It now reports all six
while retaining the existing failure, unknown, dynamic, recursive, typed-nil,
deferred-mutation, and merged-value exclusions.

## Revisit Trigger

Extend beyond direct static delegation only with an exact bounded provenance
model. Revisit recursive summaries only if a monotone fixed point can prove a
state without accepting a cycle as evidence for itself.
