# v0.5 Pre-Release Readiness Review, 2026-08-21

## Decision

Exact pushed Glippy candidate
`724d8a26eec0ef5883a28e5fee72b34a78c8284a` passes the source, formatter,
fix, analysis, configuration, contracts, race, vet, module, build, default
self-check, native budget, artifact, checksum, and reproducibility gates.
Current Oxfmt, Oxlint, Oxc, Go, and x/tools evidence does not invalidate the
implemented architecture or safety contracts.

This readiness conclusion is superseded. Later independent reviews found
material gaps, including non-aggregate typed RSS measurement and interruption
ownership plus correctness issues in LSP supersession, invalidation, lock and
WaitGroup reasoning, multi-target and incomplete-result policy, and catalog
admission. Local corrections exist, but fresh full verification, independent
source review, and exact-candidate CI remain required. Runtime RSS, signal,
interruption, and descendant-termination probes are excluded because they are
not safe to execute on the development host; aggregate memory and process
containment therefore remain unproven. No tag or release has been created.

The 98 complexity findings demonstrate why those numeric policies remain
opt-in and configurable; they are not default-signal regressions. The eleven
pedantic findings identify real simplifications and are appropriate for a
profile expected to need exceptions or cleanup. No additional correctness,
suspicious, performance, or style finding appeared. This review supports the
current profile boundaries rather than claiming that the repository follows
the complete pedantic policy.

An initial disposable run used an empty module cache and correctly reported
that `golang.org/x/sys/unix` could not be resolved with `GOPROXY=off`. Running
`go mod download` before analysis supplied the dependency and removed all
package diagnostics. This is expected evidence for Glippy's documented
no-network ordinary-analysis contract, not a source defect.
