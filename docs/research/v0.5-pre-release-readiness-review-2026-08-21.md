# v0.5 Pre-Release Readiness Review, 2026-08-21

## Decision

Local Glippy revision `c797d7ca75aaeff4e8ec646557bc78f6d152ecfb`
passes the fresh source, formatter, fix, analysis, configuration, contracts,
race, vet, module, build, and default self-check gates available on native
Darwin arm64. Current Oxfmt, Oxlint, Oxc, Go, and x/tools evidence does not
invalidate the implemented architecture or safety contracts.

This is pre-release evidence, not release-candidate completion. The local
revision is not public, the official release workflows remain pinned to Go
1.26.5, the exact pushed candidate has not run on all four native runners, and
the maintainer has not performed the final pre-tag review.

not alter its weaker overlap, release-parse, ordinary-write, suppression, or
machine-schema boundaries. The standard Go frontend remains sufficient, and
Glippy already supplies its proven no-return predicate through
`ssa.Program.SetNoReturn`.

## Rule-Noise Review

A complete non-mutating self-analysis enabled every selectable opt-in group in
addition to the configured correctness policy:

```text
glippy lint --reporter=json \
  -Wsuspicious,performance,complexity,style,pedantic ./...
```

With the module cache preloaded before Glippy entered its network-disabled
analysis path, the run completed over 308 files with 109 diagnostics, no
package diagnostics, no source problems, and the expected findings outcome.

The 98 complexity findings demonstrate why those numeric policies remain
opt-in and configurable; they are not default-signal regressions. The eleven
pedantic findings identify real simplifications and are appropriate for a
profile expected to need exceptions or cleanup. No additional correctness,
suspicious, performance, or style finding appeared. This review supports the
current profile boundaries rather than claiming that the repository follows
the complete pedantic policy.

An initial disposable run used an empty module cache and correctly reported
that `golang.org/x/sys/unix` could not be resolved with `GOPROXY=off`. Running
`go mod download` before analysis supplied the dependency and removed all
package diagnostics. This is expected evidence for Glippy's documented
no-network ordinary-analysis contract, not a source defect.
