# v0.5 Delegated Return Relationships, 2026-08-20

## Decision

Allow source-derived nil/error return relationships to cross exact static
same-arity tuple delegation through the existing bounded selected-package fact
traversal. Advance the native effect schema and persistent-cache component to
`native-effects-v10`.

## Observable Contract

A sole multi-value return expression may reuse a callee relationship only when
the call has an exact static target, the caller and callee expose the same
result count, and both related result indexes have exactly identical types.
Same-layer definitions resolve lazily through at most 4,096 active definitions.
Imported selected-package calls consume only stable facts completed by an
earlier dependency layer and intersected across package variants.

Direct explicit returns may combine with delegated returns only when every
contributing path agrees. Recursive cycles, dynamic calls, conversions,
different arities or result types, unavailable facts, unknown callee states,
and functions or deferred calls proven not to return remain unknown. Bare
returns, aliases, phis, and caller-side dominance retain their previous
conservative boundaries.

Both `nil-error-wrap` and `nilness` consume the shared relationship. Neither
rule constructs a separate call graph or loads dependency source outside the
selected local-source boundary.

## Behavioral Evidence

The focused analysis regression initially classified direct same-layer
wrappers as unknown. It now preserves both nil and non-nil error relationships,
while mutual recursion and no-return paths remain unknown.

The package regression adds an intermediate selected package between the root
and the direct helper. Before the change, `nil-error-wrap` reported the two
direct defects and missed two delegated defects. It now reports all four while
delegated ambiguous and conflicting helpers remain silent. The corresponding
`nilness` regression initially produced no diagnostics through the wrapper and
now retains the five established dereference and comparison findings.

Initial self-dogfood exposed one false positive in a compound short-circuit
failure guard. A shared successor block was treated as though entry proved one
specific error-comparison edge; block self-dominance could not establish that
edge. The regression initially produced a sixth false comparison finding.
Nilness now uses the existing exact edge-dominance proof, restoring five
findings in the fixture and removing the self-dogfood diagnostic.

## Revisit Trigger

Extend beyond sole exact static tuple delegation only with exact provenance and
edge-sensitive caller proof. Revisit recursive summaries only if a monotone
fixed point can prove a relationship without accepting a cycle as evidence for
itself.
